Description

This project implements a database that allows managing clients, employees, branches, products, inventory, sales, and purchases.

It includes relationships between tables, validations, and data integrity controls.

Content
Tables for clients, employees, and branches
Catalog of games, consoles, and products
Inventory per branch
Sales and sale details
Purchases from suppliers
Sample data included
Features
Use of primary and foreign keys
Validations with CHECK and ENUM
Duplicate prevention using UNIQUE constraints
Unified inventory (games, consoles, and products in a single table)
Applied corrections such as removal of redundant fields
Usage
Clone the repository
Run the SQL script in your database manager
